# To-Do App

A simple and interactive To-Do App built with HTML, CSS, and Vanilla JavaScript.

## 🔗 Live Demo

[live demo link](https://to-do-app-nu-coral-67.vercel.app/)

## Features

- Add new tasks
- Edit tasks
- Mark tasks as completed
- Delete individual tasks
- Search tasks
- Filter tasks by All, Pending, and Completed
- Clear all tasks
- Task statistics for total, completed, and remaining tasks
- Tasks persist after page refresh using localStorage
- Press Enter to add a task

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation
- localStorage
